Your key stays private

TapeHermes sends its saved key to NASA and returns the data. Visitors see the result without ever seeing the key.

Sites that use TapeHermes make outside calls, so they do not carry the “100% on-chain” badge.

Set up your own paid action

Open the dashboard with the wallet that owns your TapeOut site.

  1. Add the key for the service you want to use.
  2. Create an action and set its price, or make it free.
  3. Give TapeHermes permission to sign replies, then publish your API list on X Layer.
