# Dashboard UI

Keep overview, list, and other read-only views focused on information. Show forms for creating or editing data only after the user requests that action. Use a labeled dialog for short tasks or open a dedicated form in the dashboard viewer for longer tasks. An explicitly designed onboarding view may open directly to its primary form, such as adding the first site.

Use the shared shadcn Scroll Area when a dialog or panel needs to scroll. Verify the rendered interface at desktop and mobile widths before handing it back.
